# Digigamez

Nederlandse spellenbundel voor kinderen (2-7 jaar) op een 75" digibord.
Zie [PLAN.md](./PLAN.md) voor het volledige ontwerp: architectuur,
performance-aanpak, spellenlijst en deployment.

## Ontwikkelen

```bash
npm install
npm run dev
```

## Bouwen

```bash
npm run build
npm run preview
```
